# 2026-09-09 — Set 3 gets its Undead: eleven new cards, eleven carried over, and `onRise` in both phases

The owner's set-3 Undead roster (22 after Ossuary Colossus was pulled). Eleven set-1 Undead carried over by id
(`SET1_UNDEAD_IN_SET3`), four of them re-specced **in place** because set 1 is disabled (Deathswarmer 0/3,
Mumi T3 5/2, Sergeant → Sergey with new art, Anubis → "Anubis, Last Gate"); the carried texts moved to the
Shout/Echo/Rise vocabulary. Eleven new cards in `cards/set3/undead.ts`, two new Equipment (Coffin Flop,
Deathfibrillator). Set 3 stays disabled.

## The new trigger: `onRise` (R-RISE-03)

Owner: *"if minions rise in shop, that would trigger rising tide and that buff would be permanent since it's
in recruit. this will be a common trigger/effect in set 3."* One trigger from the single Rise site of each
phase — `bus.emit('onRise')` after the reborn return in combat, `fireOnRise` off `riseReturn` in the shop's
`settlePendingDeath` — with the risen body in the payload. Friendly only (side-guarded in combat; a served
board has no shop path). Revenant (Ward + stats, stacking) and Rising Tide (board + hand) are its first
watchers; Rising Tide's hand half is R-HAND-02's first real user.

## Other bodies, both phases where the phase allows

  combat, an ordinary buff in the shop).

- Soul-Lantern Hierophant: `avengeCastTribeAttack` — Watcher's Lantern body behind the shared avenge window.

## Found on the way

**Mumi's shop Echo had no own-death guard**: `fireOnFriendDeath` offers every shop death to the board's
on-death effects, so Mumi handed Rise to a random Undead whenever *any* friend was destroyed. Guarded now.

**Cage Breaker's Discover opens with the play**, before the victim's two-step death resolves (Graverobber's
ordering: the Shout's payoff belongs to the play). The death settles once the pick is made.
