# 2026-11-22: dev dashboard round two (four more parts + a visual pass)

Owner asks on the live dashboard: "what else can we add to get more visibility into overall usage" (all four groups)
and "make it more visually appealing", with Mike's site (apps/site) as the quality bar. Stacks on #2842 (Moderation)
and #2843 (New players tile).

**Data.** `supabase/migrations/2026-11-29-analytics-v2.sql` adds four service-role-only RPCs on the existing `analytics`
helpers: `analytics_players` (cohort return day 1/7/30, DAU/WAU/MAU + stickiness, games per player, hours played, a
weekday x hour heatmap), `analytics_social` (online / in game / watching now from player_presence + spectate_presence,
Versus matches by mode, Duos teams, friendships, invites, DM counts), `analytics_progression` (players per division,
points movement, levels, achievements, most equipped cosmetics and titles), `analytics_health` (crash + bug reports, the
ops health check, database size vs 500 MB, retention runs, hero / tribe / rune / Ancient trends). Six small time
indexes. Test bots and Claudebots excluded; no DM body or email is ever read.

**Page.** Analytics now has five medallion tabs (`&sec=` in the hash), a title band on the game's home scene with the
title crest, gilded section headings, area-filled charts, and one-shot entrances (transform / opacity, off under
reduced motion). Names and art for runes, Ancients, achievements, cosmetics and titles come from a second build-time
file (`game-names.json`, ~120 kB) fetched only when a round-two part opens.

**Limits.** DMs are pruned after a day, so only the last day shows. Versus rooms are retired (finished matches only).
The Live Games directory lives in the Worker, so "in a game now" is the hub presence mirror. Versus has no play clock.
Bench at ~50k games: details in apps/dash/README.md.

**Health and Balance split; Balance becomes the dev balance view (owner, same day).** "Separate health and balance",
then "add minion, spell, and rune balance data ... this will become our new dev balance view". Health and Balance are
now separate tabs and separate RPCs (`analytics_health`, `analytics_balance(from, to, tz, mode, set)`), so Health never
pays for the balance scans. Balance keeps the in-game Balance Report's honesty (2026-09-22): cards are taken vs offered
and passed, runes picked vs offered and skipped (equal access), shown as raw associations with the report's evidence
gates, Welch interval and v2 wording, never "impact" or "win rate". Reading every run's card arrays live was ~70 s for
All time at 50k runs, so cards and runes come from a nightly daily rollup (`analytics.balance_daily`, pg_cron 03:47 UTC,
today read live). The round-band adjusted comparison needs each run's `derived` stream and stays in the in-game report.
