# 2026-09-09 — Set 3 Spirits, tranche 2: the HAND-SUMMON mechanic (the last 7 of 24)

Closes the Spirit roster (tranche 1: `2026-09-09-set3-spirits-1.md`). **Owner design (2026-09-09), verbatim
in spirit:** a minion can be SUMMONED from hand once per combat. The card is NOT consumed — it stays in hand,
keeps receiving buffs (not retroactively applied to the copy), does not move; an EXACT copy is summoned at the
point of summon; the card greys in hand for the fight so it cannot be summoned again; another summoner must pick
a different card.

## The mechanic

- **Combat** — `CombatContext.summonCopyFromHand(side, uid, nearUid, ward)`: finds the hand snapshot card,
  refuses one already consumed (Rope Wrangler's `handSummonedUids`) or already copied this fight (a new
  `handCopiedUids` set), summons through the ordinary `summonMinion` with `copyStats` = the card's LIVE stats,
  its keywords and gild (+ Ward when asked), and stamps **`fromHandUid`** on the emitted `summon` event. Nothing
  is pushed to `handSummoned`, so settle leaves the hand alone. `handMinionsFor` excludes both sets, so a second
  summoner sees only fresh cards; `buffHand` still lands on a copied card (only a CONSUMED one refuses).
- **Shop twin** — `summonCopyFromHandShop` (recruit.ts) for a Rally / Echo triggered outside combat: same copy
  rule, once per card **per turn** (`RunState.handCopiedThisTurn`, cleared at the flip), board-room checked.
- **Presentation** — no new event type (six choreo registries would have wanted one): the replay reads the
  `fromHandUid` stamp. `handSummonedShownThrough` → `replay.handSummonedShown`; Recruit passes `spent` to the
  hand Card, which wears `.card.spent` (the same static grey as a locked card). The copy itself animates in as a
  normal summon.

## Cards

- **Dreamtide Caller** (T5 5/8) / **Dreaming Deep** (T7 8/14): Echo — a copy of the highest-Health hand minion
  (`ward: true` for the Deep). Golden: twice, hence two different cards.
- **Seedling Spirit** (T2 2/3): Rally — a copy of a random Spirit from hand.
- **Handbound Titan** (T6 6/10): Start of Combat — gains the highest-Health hand minion's stats this combat
  (the card untouched; golden twice). Shop-side SoC replay excused (`no-surface` — nothing temporary to grant).
- **Flamebanner Marshal** (T6 8/7): Rally — 2 friendly Spirits (golden 4) gain the highest-Attack hand minion's
  Attack, combat-only (owner: "all attack only unless engraved"); shop twin excused.
- **Hearth Whisperer** (T2 2/6, Taunt): whenever it takes damage, a random hand minion +1/+2 via `buffHand` —
  permanent (R-HAND-02), the replay grows the hand card on its beat.
- **Slumbering Colossus** (T4 4/6): the first HAND watcher on the `onTribePlayed` trigger (`inHand: true`) —
  grows +4/+4 in hand per Spirit played; asleep once on the board.
