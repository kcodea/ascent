(97 Basic / 88 Epic)**. Owner rulings applied: **no Rune of the Event Horizon**, and (a second ruling the same day) its
slot goes to the owner's pick, the **Meteor Storm** (Epic 5). Celestial ends at 10 Basic / 10 Epic.

**New shared plumbing (reused by tranche 4's Star Tap and Gem Star).**
- *"Give your Starform +A/+H" from combat.* The Starform is a Shop token, so combat banks the gain per source
  (`CombatContext.gainStarform` → `CombatCarryBacks.starformGain` → `CombatResult.playerStarformGain`, symmetric for
  self-play) and settle applies it through `buffStarform`, AFTER the deferred Shop-only Shouts so a combat Star Seed's
  creation is there to take it. This is the owner's sanctioned Starform deferral. `liveTrackingAudit` exempts it.
- *Star Crash resolves in combat.* It had no combat case in `resolveCombatSpellCastInner`, so every combat cast of it
  fizzled. The case is added (aimed Celestial + a random living friendly minion, spell power, and Rune of Falling
  Embers' bonus via the new `QuestCombatMods.starCrashBonus` / `CombatContext.starCrashBonusFor`). Any other combat
  re-cast of a Star Crash resolves now too.

**Judgement calls.**
- *The Meteor Storm's NAME.* The owner's pick was "Rune of the Meteor Shower", but that is the existing Set 3
  Celestial Epic `rune_meteor_shower` (E2, "after your first Star Crash each turn, get another"), and two runes cannot
  share a name. Built as **Rune of the Meteor Storm** (`rune_meteor_storm`); the existing Meteor Shower is untouched.
  Its extra casts run under a latch (`METEOR_ECHOING` / `meteorEchoing`), so they never repeat themselves; each copy
  adds one extra cast on a different random friendly Celestial (a Starform-aimed cast echoes onto a board Celestial).
- *Gravity is not the generic `consume` meter.* The doc said "existing runeThreshold meter consume, no engine work",
  but that meter only advances on FODDER consumes (`noteFodderConsumed`); a Starform consume never moved it. Gravity is
  a flag read in `consumeShopOffer` when the Starform is the eater (the only caller that passes `skipUid`). It buffs the
  BOARD Celestials (the P9 "your Celestials" reading), not board + hand.
- *Scattered Light*: the returned `receiver` is the first Collapse hit; with no Celestial the token still collapses
  into nothing, as a Collapse does. A second copy changes nothing, so it joins `RUNE_DUP_SWEETENER` (and so does the
  Open Grave from tranche 1: one "first destroy" a turn).
- *The Starsong* buffs every friendly Celestial including the Shouter. In combat the buff lasts the fight.
- *The Guiding Star* casts with the rune as the caster: an ungilded stand-in, so a Gilded Echo body does not double
  it (the Echoing Kobolds rule for rune-granted effects). Shop target: another board Celestial (never the dying one).
- *Stellar Echoes' graft* pays the same on a Gilded Celestial (`fixed`), and prints no note on the card, following
  Echoing Kobolds (the rune badge states the rule).
- *The Heralding Star with no Starform* does nothing (the text says "give your Starform"; it never creates one).
