# 2026-09-27 — Set 3 rune design pass, tranche 0: cuts, restores, re-tags, reprices

The first of six tranches building the owner-approved Set 3 rune design pass (owner rulings 2026-09-27 on the
design doc). Content only, no engine work. Set 3 goes from **174 runes (91 Basic / 83 Epic)** to **169 (87 / 82)**.

| Change | Runes |
|---|---|
| Cut from Set 3 only (10) | Rubywire, Living Magic, Recurrence, the Astral Draft, Refrain, the Hunting Bell, Sylus, the Pair, Quick Release, Grave Refreshment |
| Kept (owner overrode the doc) | the Golden Splinter, the Deep Feast |
| Restored to Set 3 (5) | the Open Constellation, the Festival Circuit, the Five Banners, the Strange Caravan, the Wishbone |
| Re-tagged (5) | Living Treasure: Kobold. Rising Echoes, the Crowded Crypt, Overflow: Undead. Dreamed Graves: Spirit |
| Repriced (7) | Spearline 7 -> 6, Bartering 6 -> 4, the Spirit Crown 6 -> 4, Eventide 4 -> 3, the First Round 4 -> 5, the Long Shift 2 -> 3, Body Counting every 8th death -> every 6th (`BODY_COUNTING_DEATHS`) |
| Renamed | Rune of the Grand Procession -> **Rune of the Second Showing** (id `rune_grand_procession` kept) |
| Reworded | the War Drum: "The first **Shout** you trigger each turn triggers **2** more times." (behaviour unchanged) |

**Mechanics.** A cut unscoped rune became `sets: ['set1', 'set2']`; a cut Set-3-only rune (Rubywire, the Astral
Draft, Quick Release) became `sets: []`, still resolvable by id (never archived). The Festival Circuit is the first
member of the new `hybrid` group in `set3RuneList.test.ts` (gated to both its tribes). The five re-tags are owner
rulings where the text names no tribe word, so they join `OWNER_TRIBE_RULINGS` in `tribeGate.test.ts`.

**Live Set 2 side effects (flagged).** A rune's cost and tribe gate are global, not per set. So Bartering, the First
Round and the Long Shift change price in Set 2 as well, and Overflow and Rising Echoes (now Undead-gated) leave Set 2's
Epic forge (Set 2 rolls no Undead; no Set 2 card prints Overflow, so Overflow was dead there anyway). Because Set 2
is live these got a patch-notes entry. The Set 2 static Epic pool pin moved 117 -> 115.

**Not in this tranche.** The Dwarve typo (open PR #1773). Adding Set 3 words to `runeSynergy.ts` (design P10, listed
in the doc as a separate PR and not in the owner's tranche 0 ruling). Dream Mirror stays as is (no ruling).

**Verification.** `packages/sim/src/set3RuneDesignT0.test.ts` (costs, rename, wording, cuts/restores, the Strange
Caravan's Start of Turn grant and the Five Banners' End of Turn grant working on Set 3 tribes, the re-tag gates in
Set 3 and Set 2). Pins moved with dated comments in `set3RuneList.test.ts`, `set3RuneRoster.test.ts`,
`set3RuneCuts.test.ts`, `tribeGate.test.ts`. Oracle R-SET3RUNE-01..05.
