What this counts

  • Lobby games come from Career rows (run_history), practice from practice_games, Versus from the finished match tables, the tutorial from its XP settlement.
  • Gauntlet stages leave no per-game record, so Gauntlet games are not counted.
  • A build is the client's version stamp. Versus and tutorial rows carry none, so picking a build hides them.
  • Test bots and the Claudebot test accounts are left out.
  • Players: a new player is an account whose first finished game falls in the range; a return counts only once its whole window (1, 7 or 30 days) has passed. Play time is the in-game active clock on lobby and practice games.
  • Live now comes from the friends hub's presence mirror (seen in the last 5 minutes). Messages are counted, never read, and only the last day is kept.
  • Balance trends use ranked lobby games only; rows with fewer than 10 games are dimmed.

How names are checked

  • Every account name, Duos team name and Versus room name goes through one filter. A slur is refused before it is saved. A broader list is allowed and lands here.
  • Looks fine closes the flag. Reset name sets an account to Player (the #tag kept unless taken) or clears a team name, and that name cannot be taken back.
  • A Versus room name lives only while the room is open, so it can be cleared here but not reset.
