# 2026-10-03: twelve more UI colour themes in the DEV UI Theme tuner (18 total)

Owner ask: "add 12 new color themes for the ui in the ui tuner".

- `packages/ui/src/uiThemeConfig.ts` gains 12 themes, each a full `--ui-*` token set (ghost included): Crimson Royale,
  Midnight Teal, Rose Quartz, Sunforge, Abyssal, Sandstone, Jade Dynasty, Storm Slate, Infernal, Celestial, Moss &
  Copper, Arctic Aurora. The production default is still Gem Gold, so `uiTheme.css` is unchanged apart from a comment.
- The tuner dropdown lists all 18, grouped by colour family (Gold, Fire, Violet, Blue, Green, Silver), through an
  explicit `UI_THEME_IDS` order. Labels lost their "1." numbering. The note now says "18 themes".
- A light "Ivory Parchment" theme was considered and dropped in favour of the dark Sandstone. The shared pill and
  tooltip rules hard-code dark text shadows and white hover text, so dark ink on a light plate could not read
  cleanly everywhere without changing those rules, and this ask was colours only.
- Ghost marker: Midnight Teal (lavender), Abyssal (violet), Jade (sky blue) and Aurora (ice blue) override the teal
  ghost so it never shares the accent hue. `tooltipStyle.test.ts` now also checks that the ghost hue sits at least
  25 degrees from each saturated accent (title, highlight, edge), and that the dropdown lists every theme exactly
  once. The original Frost theme sits at 28 degrees (teal ghost, ice-blue keywords), which is why the floor is 25.
- Every new theme passes the existing contrast floors (body and title 7, highlight / muted / warn 4.5, chip 7).
- Dev-only tuner work, so there is no patch note.
