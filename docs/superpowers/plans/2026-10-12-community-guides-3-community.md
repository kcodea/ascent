# Community Guides, Step 3: Publishing, Bookmarks and the Community List: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A player can publish a guide they wrote, every player can browse published guides in a Community list, bookmark the ones they like, and find their bookmarks in the lobby rail.

**Architecture:** Three new server operations (`setPublished`, `bookmark`, `unbookmark`) go through the existing `guide-write` Edge Function and three new SQL functions that are the only writers. Publishing re-checks the stored text against the word rules on the server. The client reads the Community list and the player's bookmarks directly under row-level security, paged and bounded. The Compendium Guides tab gains two pills (Bookmarked, Community) and per-card actions; the lobby rail gains a third section. Community pages live in the list component, not in the guides store.

**Tech Stack:** TypeScript, React 18, Zustand, Vitest (jsdom for UI tests), Supabase (Postgres, PostgREST, Deno Edge Functions), PGlite for executing SQL in tests, the dependency-free `@game/guides` package with generated Deno copies (`npm run guides:shared`).

**Spec:** `docs/superpowers/specs/2026-10-11-community-guides-design.md` (section 9, step 3; sections 1 to 4 and 7 for the rules). Earlier steps: `docs/devlog/2026-10-12-guides-storage.md` and `docs/devlog/2026-10-12-guides-editor.md`, whose "Carried to the next steps" lists this plan answers.

## Deviations from the spec (for the owner to confirm or veto on plan review)

1. **Publish is a button on the guide's card under My guides, not a switch inside the editor.** Publishing is its own server call with its own text re-check and its own refusals. Behind the Save button it would be two calls with two ways to fail behind one press. The card asks once before publishing ("Everyone will be able to read it"). Unpublish does not ask.
2. **The pill and the button say "Bookmarked" / "Bookmark", not "Saved".** The editor already says "Save" and "Saved to My guides." for writing a guide; using "Saved" for bookmarks as well would make one word mean two things. The sort reads "Most bookmarked". The rail's section label is "Bookmarked".
3. **The Community list grows with a "Show more guides" button, not on scroll.** No scroll listener, reachable by keyboard, and a player decides when to load more.
4. **Community pages are held by the Community list, not by the guides store.** They depend on the set, the tribe pills, the search text and the sort, and are thrown away when any of those change.
5. **A player cannot bookmark their own guide or a Team Ascent guide.** Their own would be a vote for themselves in a list ranked by bookmarks; Team Ascent guides are always in the rail already. The button is not drawn and the server refuses.
6. **Reserved names now also guard a player guide's title and tagline** ("Team Ascent", "Ascent Team", "Ascent Official", and the words admin, moderator, developer, official), on every save and at publish. Carried from step 1 ("player titles imitating Team Ascent").
7. **A Delete button on the guide's card under My guides**, asking first. Carried from step 2: it closes the dead end at the 20-guide cap, where the only Delete was inside the editor.
8. **Community search matches the title, tagline and "by" line, not the write-up.** A substring search over every write-up on the server needs an index this step does not add.
9. **Report is not in this step.** The spec's per-card Report belongs to step 4 with the rest of moderation.
10. **Write-ups stay one paragraph.** Step 2 left "may a write-up have paragraphs" as the owner's question; nothing changes here until the owner says.

Carried items this plan takes: publish re-runs the text rules; titles imitating Team Ascent; a save that is retried after a timeout never makes a second guide (a save id); a server change that does not bump `revision` reaches an open session; two nicknames with the same word; the reading view linking a card name inside a longer word; re-reading guides when the browser comes back online; Delete on the My guides card. Carried items this plan does NOT take (they stay on the list for step 4 or a polish pass): the focus pass, the "unknown" states with no way forward, the nickname-length sentence.

```sql
-- ========================================================================================================
-- GUIDES, STEP 3: publishing, bookmarks, and a save that can be retried  (2026-10-13)
-- ========================================================================================================
--
-- Paste into the Supabase SQL Editor and Run, AFTER supabase/migrations/2026-10-12-guides.sql. Idempotent: safe to
-- re-run. The same block is appended to schema.sql; keep the two identical.
-- Spec: docs/superpowers/specs/2026-10-11-community-guides-design.md. Devlog: docs/devlog/2026-10-13-guides-community.md.
--
-- WHAT
--  - `guides.last_save_id`: the id the client made for the press of Save that last wrote the row. `guide_save` given
--    the same id again by the same account answers that row and writes nothing, so a save that timed out on the
--    client but landed here is not applied twice when the player presses Save again.
--  - `guide_own_row`: the caller's own player guide, for the Edge Function to re-check its text before publishing.
--  - `guide_set_published`: the author makes a guide public or private. Publishing is refused while the team has it
--    hidden, and when the row is not at the revision whose text was checked. It counts toward the 30 an hour.
--  - `guide_bookmark`: a player bookmarks a published guide that is not theirs and not Team Ascent's (200 at most),
--    or removes a bookmark. A trigger keeps `guides.bookmark_count` true, whichever way a bookmark goes.
--  - Two indexes: the Community list's order, and bookmarks by guide (for the cascade when a guide is deleted).
--
-- A client from before this file never sends a save id or calls these functions. A client from after it, talking to
-- a database from before it: saves still work (the old `guide_save` ignores the id), and publishing and bookmarking
-- answer "something went wrong" until this file is run and `guide-write` is redeployed.

begin;

alter table public.guides add column if not exists last_save_id uuid;
create index if not exists guides_last_save on public.guides (last_save_id) where last_save_id is not null;
create index if not exists guides_community on public.guides (bookmark_count desc, published_at desc, id) where published and not hidden and not official;
create index if not exists guide_bookmarks_guide on public.guide_bookmarks (guide_id);

create or replace function public.guide_save(p_user uuid, p_doc jsonb) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_team     boolean;
  v_id       uuid := nullif(p_doc->>'id', '')::uuid;
  v_official boolean := coalesce((p_doc->>'official')::boolean, false);
  v_fork     uuid := nullif(p_doc->>'forked_from', '')::uuid;
  v_save     uuid := nullif(p_doc->>'save_id', '')::uuid; -- step 3
  v_ftitle   text;
  v_fbyline  text;
  v_row      public.guides;
  v_count    int;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  perform pg_advisory_xact_lock(hashtextextended('guides:' || p_user::text, 0));
  -- step 3: this account already made this very save (the client is pressing Save again after a timeout): answer
  -- the row it wrote. Before the rate limit, so a replay is never counted or refused.
  if v_save is not null then
    select * into v_row from public.guides where last_save_id = v_save and updated_by = p_user;
    if found then return to_jsonb(v_row); end if;
  end if;
  v_team := exists (select 1 from public.guide_team where user_id = p_user);
  if v_official and not v_team then raise exception 'not_allowed'; end if;

  select count(*) into v_count from public.guide_writes where user_id = p_user and at > now() - interval '1 hour';
  if v_count >= 30 then raise exception 'rate_limited'; end if;

  if v_id is null then
    if not v_official then
      select count(*) into v_count from public.guides where author_id = p_user and not official;
      if v_count >= 20 then raise exception 'too_many_guides'; end if;
    end if;
    if v_fork is not null then
      select title, byline into v_ftitle, v_fbyline from public.guides
       where id = v_fork and (official or (published and not hidden) or author_id = p_user);
      if not found then v_fork := null; v_ftitle := null; v_fbyline := null; end if;
    end if;
    insert into public.guides (author_id, byline, official, published, published_at, sets, tribes, pairs_with, icon_card,
                               title, tagline, body, core, enablers, mentions, aliases,
                               forked_from, forked_title, forked_byline, sort_order, updated_by, last_save_id) -- step 3: last_save_id
    values (case when v_official then null else p_user end,
            case when v_official then 'Team Ascent' else p_doc->>'byline' end,
            v_official, v_official, case when v_official then now() end,
            public.guide_text_array(p_doc->'sets'), public.guide_text_array(p_doc->'tribes'), public.guide_text_array(p_doc->'pairs_with'),
            p_doc->>'icon_card', p_doc->>'title', coalesce(p_doc->>'tagline', ''), p_doc->>'body',
            public.guide_text_array(p_doc->'core'), public.guide_text_array(p_doc->'enablers'), public.guide_text_array(p_doc->'mentions'),
            coalesce(p_doc->'aliases', '{}'::jsonb),
            v_fork, v_ftitle, v_fbyline,
            case when v_official then (select coalesce(max(sort_order), -1) + 1 from public.guides where official) else 0 end,
            p_user, v_save)
    returning * into v_row;
  else
    select * into v_row from public.guides where id = v_id for update;
    if not found then raise exception 'not_found'; end if;
    if v_row.official then
      if not v_team then raise exception 'not_allowed'; end if;
    elsif v_row.author_id is distinct from p_user then
      raise exception 'not_allowed';
    end if;
    if v_official <> v_row.official then raise exception 'not_allowed'; end if;
    if (p_doc->>'revision')::int is distinct from v_row.revision then raise exception 'conflict'; end if;
    update public.guides set
      byline     = case when v_row.official then 'Team Ascent' else p_doc->>'byline' end,
      sets       = public.guide_text_array(p_doc->'sets'),
      tribes     = public.guide_text_array(p_doc->'tribes'),
      pairs_with = public.guide_text_array(p_doc->'pairs_with'),
      icon_card  = p_doc->>'icon_card',
      title      = p_doc->>'title',
      tagline    = coalesce(p_doc->>'tagline', ''),
      body       = p_doc->>'body',
      core       = public.guide_text_array(p_doc->'core'),
      enablers   = public.guide_text_array(p_doc->'enablers'),
      mentions   = public.guide_text_array(p_doc->'mentions'),
      aliases    = coalesce(p_doc->'aliases', '{}'::jsonb),
      revision   = v_row.revision + 1,
      updated_at = now(),
      updated_by = p_user,
      last_save_id = v_save -- step 3
    where id = v_id
    returning * into v_row;
  end if;

  delete from public.guide_writes where user_id = p_user and at < now() - interval '1 day';
  insert into public.guide_writes (user_id) values (p_user);
  return to_jsonb(v_row);
end $$;

create or replace function public.guide_own_row(p_user uuid, p_id uuid) returns jsonb
language plpgsql stable security definer set search_path = public as $$
declare
  v_row public.guides;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  select * into v_row from public.guides where id = p_id;
  if not found then raise exception 'not_found'; end if;
  if v_row.official or v_row.author_id is distinct from p_user then raise exception 'not_allowed'; end if;

create or replace function public.guide_set_published(p_user uuid, p_id uuid, p_on boolean, p_revision int) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_on    boolean := coalesce(p_on, false);
  v_row   public.guides;
  v_count int;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  perform pg_advisory_xact_lock(hashtextextended('guides:' || p_user::text, 0));
  select * into v_row from public.guides where id = p_id for update;
  if not found then raise exception 'not_found'; end if;
  if v_row.official or v_row.author_id is distinct from p_user then raise exception 'not_allowed'; end if;
  if v_on = v_row.published then return to_jsonb(v_row); end if; -- already so: nothing to do, nothing counted
  if v_on then
    if v_row.hidden then raise exception 'guide_hidden'; end if;
    -- The text that was checked is the text that goes public: a save since then is a conflict.
    if p_revision is distinct from v_row.revision then raise exception 'conflict'; end if;
    select count(*) into v_count from public.guide_writes where user_id = p_user and at > now() - interval '1 hour';
    if v_count >= 30 then raise exception 'rate_limited'; end if;
  end if;
  update public.guides
     set published = v_on,
         published_at = case when v_on then coalesce(published_at, now()) else published_at end
   where id = p_id
  returning * into v_row;
  if v_on then insert into public.guide_writes (user_id) values (p_user); end if;
  return to_jsonb(v_row);
end $$;

create or replace function public.guide_bookmark(p_user uuid, p_id uuid, p_on boolean) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_on    boolean := coalesce(p_on, false);
  v_row   public.guides;
  v_count int;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  if v_on then
    perform pg_advisory_xact_lock(hashtextextended('guides:' || p_user::text, 0));
    select * into v_row from public.guides where id = p_id;
    -- A guide the caller could not read is "not found", whether it is private, hidden or was never there.
    if not found or (not v_row.official and (not v_row.published or v_row.hidden) and v_row.author_id is distinct from p_user) then
      raise exception 'not_found';
    end if;
    if v_row.official or v_row.author_id is not distinct from p_user then raise exception 'not_allowed'; end if;
    if not exists (select 1 from public.guide_bookmarks where user_id = p_user and guide_id = p_id) then
      select count(*) into v_count from public.guide_bookmarks where user_id = p_user;
      if v_count >= 200 then raise exception 'too_many_bookmarks'; end if;
```

```ts
export interface CommunityQuery {
  setId: string;
  /** Guides for any of these tribes... */
  tribes: readonly string[];
  /** ...and, when true, guides for no tribe (Neutral). */
  neutral: boolean;
  /** As typed. Cleaned here. */
  search: string;
  sort: CommunitySort;
  /** How many guides the list already holds. */
  offset: number;
}

export interface CommunityPage { guides: GuideRecord[]; more: boolean }

/**
 * Search text as it is sent: one clean line, without the characters that mean something to the filter it sits in (a
 * quote, a backslash) or to a LIKE pattern (percent, underscore, star), cut to the limit.
 */
export function communitySearch(raw: string): string {
  const s = cleanText(raw).replace(/["\\%_*]/g, ' ').replace(/\s+/g, ' ').trim();
  return [...s].slice(0, GUIDE_LIMITS.searchQuery).join('').trim();
}

/** One page of published player guides for a set. `undefined` = could not ask. */
export async function fetchCommunityPage(q: CommunityQuery): Promise<CommunityPage | undefined> {
  const c = supabaseClient();
  if (!c) return undefined;
  const tribes = q.tribes.filter((t) => TRIBE_RE.test(t));
  const tribeRule = [...(tribes.length ? [`tribes.ov.{${tribes.join(',')}}`] : []), ...(q.neutral ? ['tribes.eq.{}'] : [])];
  if (tribeRule.length === 0 || !SET_ID_RE.test(q.setId)) return { guides: [], more: false };
  const page = GUIDE_LIMITS.communityPage;
  const from = Math.max(0, Math.trunc(q.offset) || 0);
  try {
    let query = c.from('guides').select(GUIDE_COLUMNS).eq('official', false).eq('published', true).eq('hidden', false)
      .contains('sets', [q.setId]).or(tribeRule.join(','));
    const text = communitySearch(q.search);
    if (text) query = query.or(['title', 'tagline', 'byline'].map((col) => `${col}.ilike."%${text}%"`).join(','));
    if (q.sort === 'bookmarked') query = query.order('bookmark_count', { ascending: false });
    query = query.order('published_at', { ascending: false, nullsFirst: false }).order('id', { ascending: true });
    // One row more than a page, to learn whether there is another page. An explicit bound (R-NET-01).
    const res = await Promise.race([Promise.resolve(query.range(from, from + page)), timeout(READ_TIMEOUT_MS, null)]);
    if (!res || res.error) return undefined;
    const raw = (res.data as unknown[] | null) ?? [];
    const guides = raw.slice(0, page).map(parseGuideRecord).filter((g): g is GuideRecord => g !== null);
    return { guides, more: raw.length > page };
  } catch {
    return undefined;
  }
}
```

```ts
/**
 * A fresh id for one press of Save. The editor sends it with the save and again if the same document is retried, so
 * a save that timed out here but landed on the server is not applied twice. Empty when this browser cannot make one
 * (the save is then sent without it, as before).
 */
export function newSaveId(): string {
  const c: Crypto | undefined = globalThis.crypto;
  if (c && typeof c.randomUUID === 'function') return c.randomUUID();
  if (c && typeof c.getRandomValues === 'function') {
    const b = c.getRandomValues(new Uint8Array(16));
    b[6] = (b[6]! & 0x0f) | 0x40;
    b[8] = (b[8]! & 0x3f) | 0x80;
    const h = [...b].map((x) => x.toString(16).padStart(2, '0')).join('');
    return `${h.slice(0, 8)}-${h.slice(8, 12)}-${h.slice(12, 16)}-${h.slice(16, 20)}-${h.slice(20)}`;
  }
  return '';
}
```

```tsx
 * ONE GUIDE IN THE COMPENDIUM: the big card every list of the Guides tab draws (Team Ascent, My guides, Bookmarked,

  writable: boolean;

  editable: boolean;

  const ids = useMemo(() => guideCardIds(guide), [guide]);
  const { views, refs } = useGuideViews(ids, run);
  const missing = useMemo(() => guideMissingIds(guide, setId), [guide, setId]);
  const [ask, setAsk] = useState<'publish' | 'delete' | null>(null);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const run1 = async (act: () => Promise<string | null>): Promise<void> => {
    if (busy) return;

    setError(null);
    setAsk(null);

          </div>
        </div>
        <div className="bookguide-actions">
          {canBookmark && (

              aria-label={bookmarked ? `Remove the bookmark on ${guide.title}` : `Bookmark ${guide.title}`}
              onClick={() => void run1(() => onBookmark(guide, !bookmarked))}>{bookmarked ? 'Bookmarked' : 'Bookmark'}</button>
          )}
          {editable && <button type="button" className="gbtn" aria-label={`Edit ${guide.title}`} disabled={busy} onClick={() => onEdit(guide)}>Edit</button>}
          <button type="button" className="gbtn" aria-label={`Duplicate ${guide.title}`} disabled={!writable || busy} onClick={() => onDuplicate(guide)}>Duplicate</button>

                aria-description={guide.hidden ? 'Team Ascent has hidden this guide. It cannot be published.' : undefined}
                onClick={() => { setError(null); setAsk('publish'); }}>Publish</button>)}
          {own && <button type="button" className="gbtn" aria-label={`Delete ${guide.title}`} disabled={!writable || busy} onClick={() => { setError(null); setAsk('delete'); }}>Delete</button>}
        </div>
      </header>
      {ask === 'publish' && (

          <span>Publish this guide? Everyone will be able to read it.</span>

        </p>

      {error && <p className="gtool-note bookguide-ask" role="alert">{error}</p>}

      </div>
    </article>
  );
});
```

```tsx
import { memo, useCallback, useEffect, useRef, useState, type CSSProperties } from 'react';
import type { Tribe } from '@game/core';
import type { SetId } from '@game/content';
import { GUIDE_LIMITS } from '@game/guides';
import { LazyCell, LazyRootProvider } from '../bookLazy';
import { sfx } from '../sfx';
import { toGuide, type Guide } from './guides';
import { communitySearch, fetchCommunityPage, type CommunitySort } from './guidesRemote';

/** How long the search box must rest before the server is asked. */
const SEARCH_PAUSE_MS = 300;

interface Listed {
  /** The question this list answers. */
  key: string;
  guides: Guide[];
  /** How many rows the server has been asked for so far (the next page starts here). */
  next: number;
  more: boolean;
  status: 'loading' | 'ready' | 'failed';
}

/**
 * THE COMMUNITY LIST: published player guides for the shown set, read from the server one page at a time.
 *
 * The question is the set, the tribe rule, the search text and the sort. When any of them changes, the list starts
 * again from the first page; "Show more guides" adds the next page. Pages live here, not in the guides store: they
 * answer one question and are thrown away when it changes.
 *
 * A SLOW ANSWER NEVER WINS. Each ask takes a number; an answer is used only if no newer ask has been made since. So
 * typing, switching the sort or lighting a tribe pill mid-flight can never be undone by an older answer landing late.
 *
 * SEARCH WAITS FOR A PAUSE (300 ms), so typing a word asks once.
 *
 * The host draws each card (`renderCard`): which buttons a card shows, and whether it is bookmarked, is the host's
 * knowledge. PERFORMANCE: cards mount through `LazyCell` (the first two at once, the rest near the viewport); nothing
 * animates; no scroll listener.
 */
export const CommunityGuides = memo(function CommunityGuides({ setId, queryTribes, neutral, search, root, renderCard }: {
  setId: SetId;
  /** Guides for any of these tribes... */
  queryTribes: readonly Tribe[];
  /** ...and, when true, guides for no tribe. */
  neutral: boolean;
  /** The Compendium's search box, as typed. */
  search: string;
  /** The scroll box the lazy cells watch. */
  root: HTMLDivElement | null;
  renderCard: (g: Guide, eager: boolean) => JSX.Element;
}): JSX.Element {
  const [sort, setSort] = useState<CommunitySort>('bookmarked');
  const [text, setText] = useState(() => communitySearch(search));
  useEffect(() => {
    const cleaned = communitySearch(search);
    const t = window.setTimeout(() => setText(cleaned), SEARCH_PAUSE_MS);
    return () => window.clearTimeout(t);
  }, [search]);

  const tribesKey = queryTribes.join(',');
  const key = `${setId}|${tribesKey}|${neutral ? 1 : 0}|${text}|${sort}`;
  const [list, setList] = useState<Listed>({ key, guides: [], next: 0, more: false, status: 'loading' });
  const asks = useRef(0);
  useEffect(() => () => { asks.current += 1; }, []); // gone: no answer may be used

  const load = useCallback(async (offset: number): Promise<void> => {
    asks.current += 1;
    const mine = asks.current;
    setList((cur) => (offset === 0 ? { key, guides: [], next: 0, more: false, status: 'loading' } : { ...cur, status: 'loading' }));
    const page = await fetchCommunityPage({ setId, tribes: tribesKey ? tribesKey.split(',') : [], neutral, search: text, sort, offset });
    if (mine !== asks.current) return;
    if (!page) { setList((cur) => ({ ...cur, key, status: 'failed' })); return; }
    const fresh = page.guides.map(toGuide).filter((g): g is Guide => g !== null);
    setList((cur) => {
      const kept = offset === 0 ? [] : cur.guides;
      const have = new Set(kept.map((g) => g.rowId));
      return { key, guides: [...kept, ...fresh.filter((g) => !have.has(g.rowId))], next: offset + GUIDE_LIMITS.communityPage, more: page.more, status: 'ready' };
    });
  }, [key, setId, tribesKey, neutral, text, sort]);

  // A new question: start again from the first page.
  useEffect(() => { void load(0); }, [load]);

  const pick = (s: CommunitySort): void => { if (s !== sort) { sfx.tick(); setSort(s); } };
  const pill = { '--c': 'var(--ui-title)' } as CSSProperties;
  const shown = list.key === key ? list.guides : [];
  return (
    <>
      <div className="gtool-pills gcomm-sort" role="group" aria-label="Order the Community guides">
        <button type="button" className={`book-runetribe${sort === 'bookmarked' ? ' on' : ''}`} style={pill} aria-pressed={sort === 'bookmarked'} onClick={() => pick('bookmarked')}>Most bookmarked</button>
        <button type="button" className={`book-runetribe${sort === 'newest' ? ' on' : ''}`} style={pill} aria-pressed={sort === 'newest'} onClick={() => pick('newest')}>Newest</button>
      </div>
      {list.status === 'failed' && (
        <p className="gtool-note" role="alert">
          <span>Could not load the Community guides.</span>
          <button type="button" className="gbtn" onClick={() => void load(shown.length === 0 ? 0 : list.next)}>Try again</button>
        </p>
      )}
      {shown.length === 0 && list.status === 'loading' && <p className="gtool-note" role="status">Loading the Community guides.</p>}
      {shown.length === 0 && list.status === 'ready' && (
        <div className="book-empty gtool-empty">No Community guides match. Publish one of yours from My guides to be the first.</div>
      )}
      {shown.length > 0 && (
        <LazyRootProvider root={root}>
          {shown.map((g, i) => (
            <LazyCell key={g.id} eager={i < 2} className="bookguide-slot">{() => renderCard(g, i < 2)}</LazyCell>
          ))}
        </LazyRootProvider>
      )}
      {shown.length > 0 && list.more && list.status !== 'failed' && (
        <div className="gcomm-more">
          <button type="button" className="gbtn" disabled={list.status === 'loading'} onClick={() => void load(list.next)}>Show more guides</button>
        </div>
      )}
    </>
  );
});
```
