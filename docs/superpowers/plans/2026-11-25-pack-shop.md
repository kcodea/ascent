# The Pack Shop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dev-only Shop Lab where packs stand on a shelf, are bought by dragging them across a counter line into a hand, and are opened by dragging them from the hand to the pedestal, handing off to the existing `PackOpener`.

**Architecture:** A Pixi scene (`shopScene.ts`) draws everything that moves; a React shell (`PackShop.tsx`) owns words, controls, the purchase call and accessibility. Layout, the drag state machine and the tag text are pure, tested files. Data comes through a small contract in `@game/progression`; the lab supplies a fake catalog, wallet and hand.

**Tech Stack:** TypeScript, React 18, PixiJS v8 (WebGL, GLSL ES 3.0 via `Shader.from`), Vitest (+ jsdom for `.test.tsx`), the existing pack-opening modules.

**Spec:** `docs/superpowers/specs/2026-11-25-pack-shop-design.md` (read sections 4, 6, 7 and 14 before any task).

## Review Focus

1. **A purchase answer that never comes** (timeout / network): the pack must not be stuck at the hand, and a retry of the same offer at the same price must reuse the request id. Test in Task 8.
2. **The price moves between pick-up and release** (`price_changed`): the pack returns, the new price shows, nothing is charged twice. Test in Task 8.
3. **Release exactly on the counter line, or a resize mid-drag:** not bought; the pack returns to where it came from. Tests in Tasks 3 and 8.
4. **A second pick-up while a purchase is pending,** including by keyboard: refused. Tests in Tasks 3 and 8.
5. **An empty shelf, an empty hand, and a hand of 30 packs:** nothing throws, the pile count is right. Tests in Tasks 2 and 8.

### Task 3: `shopDrag.ts` (pure state machine)

**Files:** Create `packages/ui/src/progression/packShop/shopDrag.ts`, `shopDrag.test.ts`.

**Interfaces:**
- Consumes: `ShopLayout` (Task 2).
- Produces:

```ts
export type DragPhase = 'idle' | 'heldShelf' | 'buying' | 'toHand' | 'toShelf' | 'heldHand' | 'toPedestal' | 'toHandBack';
export type DragZone = 'shelf' | 'hand' | 'pedestal';
export type DropAction = 'buy' | 'return' | 'play' | 'none';
export interface ShopDrag { phase: DragPhase; id: string | null; overLine: boolean }
export const newDrag = (): ShopDrag;
/** `hand` only strictly below the line; `pedestal` within 0.6 pedestal heights of the pedestal's centre; else `shelf`. */
export function zoneAt(L: ShopLayout, x: number, y: number): DragZone;
export function pickUp(d: ShopDrag, from: 'shelf' | 'hand', id: string): boolean;   // false unless idle
export function moveHeld(d: ShopDrag, zone: DragZone, affordable: boolean): void;    // overLine = heldShelf && zone === 'hand' && affordable
export function release(d: ShopDrag, zone: DragZone, affordable: boolean): DropAction;
export function buySettled(d: ShopDrag, ok: boolean): void;   // buying -> toHand | toShelf
export function cancelHeld(d: ShopDrag): DropAction;          // a resize / lost pointer: always 'return'
export function arrived(d: ShopDrag): void;                   // any travelling phase -> idle
```

Transitions: `heldShelf` + release in `hand` + affordable → `buying`, action `buy`; any other `heldShelf` release → `toShelf`, `return`. `heldHand` + release in `pedestal` → `toPedestal`, `play`; else → `toHandBack`, `return`. `release` when not held → `none`.
