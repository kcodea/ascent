## Runes (`duosRunes.ts`, new `duosRune` kinds)

- **Hand-Me-Downs** (1): `settleMinionSale` -> `gold` team effect, first 2 sales a turn (`N/2 this turn` tally).
- **Buddy System** (2): reducer buy block -> `buffLeftmost` (+3/+2 per copy, `runeId` names the buff), no limit.
- **Gild Pact** (2): the holder's rune sends a `listen { what: 'gild' }` team effect; from then on the teammate's
  `noteGilded` (the one gild chokepoint) sends `mateGild`. The holder's run answers: 2 Gold Pouches per copy here, and
  the same gifted back (from the rune badge).
- **Teammate Synergy REWORKED** (owner 2026-11-01: "i meant teammate synergy - change it to be when you get a triple
  reward, your teammate does too. (3 per game)"; R-DUOS-RUNES-05): fires from `grantGoldenDiscover` (the one Triple Reward
  grant) for every reward that landed, any source. The `tripleReward` team effect carries `tier` (the sender's
  `grantedTier`) and `synergy: true`; the receiver grants at that tier and never fires its own Synergy for it (no
  ping-pong). The "twin gilding" Epic from the first cut of this PR is gone: that was the owner's meaning.
- **Pep Talk** (1; owner change 2026-11-01: "change pep talk to 'when you trigger a shout' instead of your teammate",
  target = the teammate's left-most): the holder's per-action Shop Shout count sends one `buffLeftmost` (+2/+3 per Shout
  per copy, `runeId`, streaming from the rune badge), permanent on the teammate's run. COMBAT: `QuestCombatMods.duosPepTalk`
  on the holder's side; in `simulate`, while the holder's board fights (its live mods) and the teammate's board is still
  the waiting reserve, every `battlecryTriggered` on that side buffs the reserve's locked board[0] (a per-fight copy,
  combat-only), so the teammate steps in already buffed. Symmetric.
- New `TeamEffect` kinds: `listen`, `mateGild`; `buffLeftmost.runeId`. The Worker only checks that `team` is
  an object, so it needs no change. `passLob.ts` SENDS now includes `buffLeftmost` (Buddy System streams from its badge).
