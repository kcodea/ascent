# 2026-09-27 — Set 3 rune design pass, tranche 4: hybrids (8 runes)

Stacked on tranche 3 (`feat/set3-runes-t3`). Eight hybrid runes, all `sets: ['set3']`, each gated to its two tribes.
Set 3 is now **200 runes (107 Basic / 93 Epic)**. With the restored Festival Circuit (Spirit + Celestial) and Soul
Script (Undead + Celestial, listed under Undead), every one of the 10 tribe pairs has exactly one hybrid. Owner rulings
applied: **no Tavern Tab** (the Dwarf + Spirit slot is the owner's pick, Last Call); **Minted Gems** gets a *random*
Ruby; the **Grim Toast** shares the whole live Aura, not a mirror of Attack gains; the **Keepsake Gem** is the stronger
version (every Ruby, Epic 4).

**Judgement calls.**
- *Last Call ships as "Rune of Closing Time".* The Set 2 Dwarf rune `rune_last_call` is already "Rune of Last Call"
  (a different effect: Avenge (4), 2 Ales). Names are unique per set, so the owner's name would pass the validator,
  but two different runes under one name is the collision the content rules warn about. One-line rename if the owner
  prefers the original.
- *The Grim Toast* folds the Aura into a Dwarf at display time, exactly like the Undead's Lantern channel. The Undead
  buy channel is baked into an Undead at buy, but never into a Dwarf, so a Dwarf folds it too (and combat seeds it on
  every Dwarf, not only a from-base body). A mid-fight Aura rise lands on the living Dwarves as a combat buff; in the
  Shop the Aura is a display fold (as for the Undead), so a Shop rise is not a "gains Attack" event for Kneel or the
  Anvil. Discover previews do not fold it, the same as they do not fold the Undead Aura today.
- *The Keepsake Gem* relays the Ruby's stats (and, in the Shop, its Kobold keyword rider) as a plain stat grant, never
  a cast, so Double Trouble, Candle Conduit, the Gem Star and every other Ruby watcher hear one Ruby per cast. In combat
  it relays stats only (hand buffs carry no keyword).
- *The Gem Star's count* is per turn: the Shop's casts, then that turn's combat gets what is left (`gemStarLeft`).
  A Shop cast needs a Starform to count; a combat cast is banked (the Starform deferral).
- *The Pallbearer* counts every friendly Undead death, including a board-full Rise that stays dead (both combat
  friendly-death tallies emit the victim). Sales never count.

**Live text.** Minted Gems' badge is the generic meter (`x/8g`). New badges: the Grim Toast prints the Aura your
Dwarves get now (`+A/+H`), the Gem Star this turn's count (`n/4`).
