# 2026-09-27 — Set 3 rune design pass, tranche 1: Undead (8 runes)

Stacked on tranche 0 (`feat/set3-runes-t0`). Undead had the fewest runes of any Set 3 tribe; this adds 8, all
`sets: ['set3']` and Undead-gated. Set 3 is now **177 runes (92 Basic / 85 Epic)**. Owner rulings applied: Rune of the
Soul Toll is built instead of the doc's Unquiet, and there is no Mortal Coil.

**Engineering call: no generic `runeOnEvent` kind (yet).** Every new rune is a `combatFlag` reward (questFlags +
`flagCopies`, the established pattern) with a hook at the phase's chokepoint. The recurring *payouts* are shared
helpers instead: `raiseUndeadAuraShop` / `raiseUndeadAura` (Shop / combat "give your Undead Aura +N Attack"). A generic
reward kind would still need a hook at each event's chokepoint in each phase; the payout helpers are where the reuse
actually is. Revisit if tranches 2-4 show the event side repeating too.

**The Soul Furnace, the one fold.** The derived Health term (`soulFurnaceHealth` in core: ceil(Aura Attack / 2) per
copy, Aura Attack = `undeadAttackBonus + undeadBuyAtk`) is kept INSIDE `undeadHealthBonus`; `soulFurnaceHp` records the
slice so a re-sync moves only the difference. So every existing reader (the board / hand / Shop fold, `instView`,
combat seeding via `undeadHp`, served snapshots, the Aura pill) folds it with no new plumbing. Combat is seeded with
the term and re-derives it live when the Aura's Attack rises (`grantUndeadAura`, `grantUndeadBuyAtk`); that live
delta rides `undeadAura.health` for later bodies but is never added to `undeadAuraGain`, so settle cannot double it.

**Judgement calls.**
- *Aura Attack for the Soul Furnace* includes the buy channel (Deathswarmer, Forsaken Mage), not only the Lantern:
  both are printed as "your Undead Aura" and the Aura pill sums them.
- *Half rounds up* (the doc's ceil).
- *"Give your Undead Aura +N Attack"* (Wake, Soul Toll) raises the Lantern channel (folded, retroactive), not the buy
  channel.
- *The Open Grave* skips a minion that already has Rise (the charge is kept). A loan expiry (Funeral on Loan) is not
  a destroy and never arms it.
- *The Gravedigger* excludes the dying body (the deferred path still has it on the board). In the immediate path the
  buff lands after the Rise return, so a risen Undead is buffed; in the deferred path the Rise is its own later beat.
- *Rise runes' order*: the minion Rise watchers first, then the Second Wind, then the Restless (so the Echo sees the
  grown body). Combat and Shop match.
- *The Soul Toll* is combat-only, like every Avenge (the Shop has no Avenge).
