# Community Guides, Step 4: Moderation and Release Tools: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Players can report a published guide; the team can hide, unhide and delete any player's guide and work through reports in the game; the team can carry guides over to a new set and refresh the built-in guides from the live ones.

**Architecture:** Four new server operations (`report`, `setHidden`, `resolveReport`, `retagSets`) go through the existing `guide-write` Edge Function and four new SQL functions that are the only writers. The team reads reports and hidden guides directly under row-level security (already team-only). A Reports pill, drawn only for the team, holds open reports, hidden guides and the carry-over tool. A repo script regenerates the built-in guides file from the live Team Ascent guides with the public key.

**Tech Stack:** TypeScript, React 18, Zustand, Vitest (jsdom for UI tests), Supabase (Postgres, PostgREST, Deno Edge Functions), PGlite for executing SQL in tests, the dependency-free `@game/guides` package with generated Deno copies (`npm run guides:shared`).

**Spec:** `docs/superpowers/specs/2026-10-11-community-guides-design.md` (section 9, step 4; sections 1, 3, 4, 5 and 6 for the rules). Earlier steps' devlogs, whose "Carried to the next steps" lists this plan answers: `docs/devlog/2026-10-12-guides-storage.md`, `docs/devlog/2026-10-12-guides-editor.md`, `docs/devlog/2026-10-12-guides-community.md`.

## Deviations from the spec (for the owner to confirm or veto on plan review)

1. **The Reports pill holds three things, not one:** open reports, hidden guides, and Carry guides over. The spec puts Carry guides over there already; hidden guides need a home so a guide hidden without a report (straight from Community) can be found and unhidden.
2. **Dismiss is per guide, not per report.** A guide's open reports are shown together ("3 reports: 2 Offensive, 1 Spam") and dismissed together.
3. **Carry guides over only ever ADDS the new set to a guide.** It never removes a set. The spec says a card archived mid-set does not untag a guide; recomputing every tag would do exactly that.
4. **The team cannot hide a Team Ascent guide.** They edit or delete it. (A hidden official guide would still be readable under the read rule, which is step 1's design.)
5. **A report's note is not word-filtered.** Only the team reads it. It is cleaned and limited to 300 characters.
6. **Bookmark changes get a rate limit of 120 an hour.** Carried from step 3's review; the number is the owner's to change.
7. **The "Based on" line is re-checked at publish.** Carried from step 3's review. If the source guide's title or by line now breaks the word rules, the copy cannot be published and the player is told why.
8. **`npm run guides:pull` rewrites `guides.bundled.ts` whole.** Hand-written comments inside that file's entries are lost on the first pull. The owner's exact titles and card lists stop being pinned by tests, as the spec says.
9. **Blocking an account is not in this step** (and not in the spec). A hidden guide's author can still publish a copy; the Reports pill is where the team sees it come back.
10. **No Report on your own guide or on a Team Ascent guide.** The button is not drawn and the server refuses.

Carried items this plan takes: Report, Hide, Unhide and Delete for the team in the game (replacing the runbook's SQL); the bookmark rate limit; the "Based on" re-check; a hidden Team Ascent guide (refused); the team seeing a guide whose author republished it as a copy (it appears in Community like any guide). Not taken (they stay for a polish pass): the focus pass, a distinct look for a pressed Bookmark button, the Community bookmark count moving at once, the "unknown" states with no way forward, paragraphs in write-ups, the server comparing content on a replayed save id.

```ts
export type ReportValidation = { ok: true; reason: ReportReason; note: string } | { ok: false; error: 'bad_report'; field: 'reason' | 'note' | 'report' };

/** A report as the server accepts it: one of the four reasons, and a clean note of at most the limit (empty is fine). */
export function validateReport(v: unknown): ReportValidation {
  if (!v || typeof v !== 'object' || Array.isArray(v)) return { ok: false, error: 'bad_report', field: 'report' };
  const o = v as Record<string, unknown>;
  const reason = REPORT_REASONS.find((r) => r === o.reason);
  if (!reason) return { ok: false, error: 'bad_report', field: 'reason' };
  if (o.note !== undefined && o.note !== null && typeof o.note !== 'string') return { ok: false, error: 'bad_report', field: 'note' };
  const note = cleanText(o.note);
  if (len(note) > GUIDE_LIMITS.reportNote) return { ok: false, error: 'bad_report', field: 'note' };
  return { ok: true, reason, note };
}
```

```sql
-- GUIDES, STEP 4: reports, hiding, carrying guides over to a new set, a limit on bookmark changes  (2026-10-14)

-- Paste into the Supabase SQL Editor and Run, AFTER 2026-10-12-guides.sql and 2026-10-13-guides-community.sql.
-- Idempotent: safe to re-run. The same block is appended to schema.sql; keep the two identical.

-- Spec: docs/superpowers/specs/2026-10-11-community-guides-design.md. Devlog: docs/devlog/2026-10-14-guides-moderation.md.
--
-- WHAT
--  - `guide_bookmark_log`: one row per bookmark added or removed, for the 120-an-hour limit. The service role's alone.
--  - `guide_bookmark`: as before, plus that limit. A call that changes nothing is not counted.
--  - `guide_report`: a signed-in player reports someone else's published guide, once per guide, ten a day.
--  - `guide_set_hidden`: the team hides or unhides a player's guide. A hidden guide is read only by its author and
--    the team; hiding marks its open reports actioned. A Team Ascent guide cannot be hidden (edit or delete it).
--  - `guide_dismiss_reports`: the team dismisses every open report of a guide.
--  - `guide_retag_set`: the team adds one set to up to 200 named guides (a new set going live). It only ever adds:
--    a card archived mid-set must not untag a guide.
-- Reports are read by the team only (the step 1 policy on `guide_reports`); a reporter cannot read their own.

create table if not exists public.guide_bookmark_log (
  user_id uuid not null references auth.users(id) on delete cascade,
  at      timestamptz not null default now()
);
create index if not exists guide_bookmark_log_user_at on public.guide_bookmark_log (user_id, at desc);
alter table public.guide_bookmark_log enable row level security; -- no policy: the service role only

create or replace function public.guide_bookmark(p_user uuid, p_id uuid, p_on boolean) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_on      boolean := coalesce(p_on, false);
  v_row     public.guides;
  v_count   int;
  v_changed boolean := false; -- step 4
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  perform pg_advisory_xact_lock(hashtextextended('guides:' || p_user::text, 0)); -- step 4: both paths, for the limit
  -- step 4: at most 120 changes an hour. Checked before anything is read, so it cannot be used to probe.
  select count(*) into v_count from public.guide_bookmark_log where user_id = p_user and at > now() - interval '1 hour';
  if v_count >= 120 then raise exception 'rate_limited'; end if;
  if v_on then
    select * into v_row from public.guides where id = p_id;
    -- A guide the caller could not read is "not found", whether it is private, hidden or was never there.
    if not found or (not v_row.official and (not v_row.published or v_row.hidden) and v_row.author_id is distinct from p_user) then
      raise exception 'not_found';
    end if;
    if v_row.official or v_row.author_id is not distinct from p_user then raise exception 'not_allowed'; end if;
    if not exists (select 1 from public.guide_bookmarks where user_id = p_user and guide_id = p_id) then
      select count(*) into v_count from public.guide_bookmarks where user_id = p_user;
      if v_count >= 200 then raise exception 'too_many_bookmarks'; end if;
      insert into public.guide_bookmarks (user_id, guide_id) values (p_user, p_id) on conflict do nothing;
      v_changed := found; -- step 4
    end if;
  else
    delete from public.guide_bookmarks where user_id = p_user and guide_id = p_id;
    v_changed := found; -- step 4
  end if;
  if v_changed then -- step 4
    delete from public.guide_bookmark_log where user_id = p_user and at < now() - interval '1 day';
    insert into public.guide_bookmark_log (user_id) values (p_user);
  end if;
  return jsonb_build_object('bookmarked', v_on, 'count',
    coalesce((select bookmark_count from public.guides where id = p_id and published and not hidden), 0));
end $$;

create or replace function public.guide_report(p_user uuid, p_id uuid, p_reason text, p_note text) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_row   public.guides;
  v_count int;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  if p_reason is null or p_reason not in ('offensive', 'spam', 'impersonation', 'other') then raise exception 'bad_report'; end if;
  if char_length(coalesce(p_note, '')) > 300 then raise exception 'bad_report'; end if;
  perform pg_advisory_xact_lock(hashtextextended('guides:' || p_user::text, 0));
  select * into v_row from public.guides where id = p_id;
  if not found or (not v_row.official and (not v_row.published or v_row.hidden) and v_row.author_id is distinct from p_user) then
    raise exception 'not_found';
  end if;
  if v_row.official or v_row.author_id is not distinct from p_user then raise exception 'not_allowed'; end if;
  if exists (select 1 from public.guide_reports where guide_id = p_id and reporter_id = p_user) then raise exception 'already_reported'; end if;
  select count(*) into v_count from public.guide_reports where reporter_id = p_user and created_at > now() - interval '1 day';
  if v_count >= 10 then raise exception 'report_limit'; end if;
  insert into public.guide_reports (guide_id, reporter_id, reason, note) values (p_id, p_user, p_reason, coalesce(p_note, ''));
  return jsonb_build_object('reported', true);
end $$;

create or replace function public.guide_set_hidden(p_user uuid, p_id uuid, p_on boolean) returns jsonb
language plpgsql security definer set search_path = public as $$
declare
  v_on  boolean := coalesce(p_on, false);
  v_row public.guides;
begin
  if p_user is null then raise exception 'unauthenticated'; end if;
  if not exists (select 1 from public.guide_team where user_id = p_user) then raise exception 'not_allowed'; end if;
  select * into v_row from public.guides where id = p_id for update;
  if not found then raise exception 'not_found'; end if;
  if v_row.official then raise exception 'not_allowed'; end if; -- a Team Ascent guide is edited or deleted, not hidden
  update public.guides
     set hidden = v_on,
         hidden_by = case when v_on then p_user end,
         hidden_at = case when v_on then now() end
   where id = p_id
  returning * into v_row;
  if v_on then
    update public.guide_reports set status = 'actioned', resolved_by = p_user, resolved_at = now()
     where guide_id = p_id and status = 'open';
  end if;
  return to_jsonb(v_row);
end $$;

language plpgsql security definer set search_path = public as $$

begin

   where id = any(p_ids) and not (p_set = any(sets));
  get diagnostics v_n = row_count;
  return jsonb_build_object('tagged', v_n);
end $$;
```

```ts
/**
 * GUIDES: two pure helpers for the team's Reports pill.
 *
 *  - `groupReports`: the open reports, one group per guide, the most reported first.
 *  - `planCarryOver`: which guides a new set should be added to. A guide carries over when every Core card, Enabler and
 *    named card is in the new set's pool and its tribes are on the new set's roster (`guideSetsFor`, the same rule a
 *    save uses). It only ever ADDS the set: a guide that fails is left as it is (owner 2026-10-11: a card archived
 *    mid-set does not untag a guide).
 */
import { guideSetsFor, type GuideRecord, type ReportReason, type SetFacts } from '@game/guides';
import type { GuideTagRow, OpenReport } from './guidesRemote';

export interface ReportGroup {
  guide: GuideRecord;
  count: number;
  /** Each reason given, most given first. */
  reasons: Array<[ReportReason, number]>;
  /** The notes that say something, newest first, five at most. */
  notes: string[];
  latestAt: string;
}

const MAX_NOTES = 5;

export function groupReports(reports: readonly OpenReport[]): ReportGroup[] {
  const byGuide = new Map<string, OpenReport[]>();
  for (const r of reports) {
    const list = byGuide.get(r.guideId);
    if (list) list.push(r); else byGuide.set(r.guideId, [r]);
  }
  const groups: ReportGroup[] = [];
  for (const list of byGuide.values()) {
    const newest = [...list].sort((a, b) => b.createdAt.localeCompare(a.createdAt));
    const tally = new Map<ReportReason, number>();
    for (const r of list) tally.set(r.reason, (tally.get(r.reason) ?? 0) + 1);
    groups.push({
      guide: newest[0]!.guide,
      count: list.length,
      reasons: [...tally.entries()].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0])),
      notes: newest.map((r) => r.note.trim()).filter((n) => n !== '').slice(0, MAX_NOTES),
      latestAt: newest[0]!.createdAt,
    });
  }
  return groups.sort((a, b) => b.count - a.count || b.latestAt.localeCompare(a.latestAt) || a.guide.id.localeCompare(b.guide.id));
}

export interface CarryPlan {
  /** The guides to add the set to. */
  carry: string[];
  /** Guides that do not fit the set and stay as they are. */
  stay: number;
  /** Guides that already carry it. */
  already: number;
}

export function planCarryOver(rows: readonly GuideTagRow[], target: string, facts: readonly SetFacts[]): CarryPlan {
  const set = facts.filter((f) => f.id === target);
  const plan: CarryPlan = { carry: [], stay: 0, already: 0 };
  for (const r of rows) {
    if (r.sets.includes(target)) { plan.already += 1; continue; }
    if (set.length > 0 && guideSetsFor(r, set).length > 0) plan.carry.push(r.id);
    else plan.stay += 1;
  }
  return plan;
}

/** A list cut into runs of at most `size`, in order. */
export function batches<T>(items: readonly T[], size: number): T[][] {
  const out: T[][] = [];
  for (let i = 0; i < items.length; i += Math.max(1, size)) out.push(items.slice(i, i + Math.max(1, size)));
  return out;
}
```

```ts
import type { GuideRecord } from './types';

export interface BundledSourceGuide {
  id: string;
  set: string;
  tribes: string[];
  pairsWith: string[];
  iconCard: string;
  title: string;
  tagline: string;
  body: string;
  core: string[];
  enablers: string[];
  mentions: string[];
  aliases: Record<string, string>;

/** The Team Ascent guides, in their order, as the built-in file holds them. A guide with no set cannot be shown and is left out. */
export function recordsToBundled(records: readonly GuideRecord[]): BundledSourceGuide[] {
  return records
    .filter((r) => r.official && r.sets.length > 0)
    .slice()
    .sort((a, b) => a.sortOrder - b.sortOrder || a.id.localeCompare(b.id))
    .map((r) => ({
      id: r.slug ?? r.id, set: r.sets[0]!, tribes: [...r.tribes], pairsWith: [...r.pairsWith], iconCard: r.iconCard, title: r.title, tagline: r.tagline,
      body: r.body, core: [...r.core], enablers: [...r.enablers], mentions: [...r.mentions], aliases: { ...r.aliases },
    }));
}

const BACKSLASH = String.fromCharCode(92);
const hex4 = (n: number): string => n.toString(16).padStart(4, '0');

/** A single-quoted TypeScript string literal, plain ASCII. */
function quote(s: string): string {
  let out = "'";
  for (let i = 0; i < s.length; i++) {
    const code = s.charCodeAt(i);
    const ch = s[i]!;
    if (ch === BACKSLASH) out += BACKSLASH + BACKSLASH;
    else if (ch === "'") out += BACKSLASH + "'";
    else if (code < 32 || code > 126) out += `${BACKSLASH}u${hex4(code)}`;
    else out += ch;
  }
  return `${out}'`;
}
const list = (xs: readonly string[]): string => `[${xs.map(quote).join(', ')}]`;
```

```ts
/**
 * `npm run guides:pull`: rewrite packages/ui/src/guides/guides.bundled.ts from the LIVE Team Ascent guides, so the
 * offline fallback matches what players see online. Read-only against the server: one anonymous GET of public rows
 * (official guides are readable by everyone). Run it before a release, then run `npm test` and commit the file.
 *
 * It refuses to write when the server answers no guides (a project with no import yet), so a mistake cannot empty
 * the fallback.
 */
import { readFileSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { recordsToBundled, renderBundledGuides } from '../../guides/src/bundledSource';
import { parseGuideRecord, type GuideRecord } from '../../guides/src/types';

const root = join(fileURLToPath(new URL('.', import.meta.url)), '../../..');
const COLUMNS = 'id,slug,author_id,byline,official,published,published_at,hidden,sets,tribes,pairs_with,icon_card,title,tagline,body,core,enablers,mentions,aliases,forked_from,forked_title,forked_byline,bookmark_count,sort_order,revision,created_at,updated_at';
/** Official guides are few (the team writes them). One bounded request; more than this is a mistake worth stopping on. */
const LIMIT = 1000;

function env(): { url: string; key: string } {
  const e = Object.fromEntries(
    readFileSync(join(root, 'apps/web/.env'), 'utf8').split(/\r?\n/)
      .filter((l) => l && !l.startsWith('#') && l.includes('='))
      .map((l) => [l.slice(0, l.indexOf('=')).trim(), l.slice(l.indexOf('=') + 1).trim()]),
  );
  if (!e.VITE_SUPABASE_URL || !e.VITE_SUPABASE_ANON_KEY) throw new Error('no backend configured in apps/web/.env');
  return { url: e.VITE_SUPABASE_URL, key: e.VITE_SUPABASE_ANON_KEY };
}

async function main(): Promise<void> {
  const { url, key } = env();
  const res = await fetch(`${url}/rest/v1/guides?select=${COLUMNS}&official=eq.true&order=sort_order.asc,id.asc&limit=${LIMIT}`, {
    headers: { apikey: key, Authorization: `Bearer ${key}` },
  });
  if (!res.ok) throw new Error(`the server answered ${res.status}`);
  const rows = (await res.json()) as unknown[];
  if (!Array.isArray(rows)) throw new Error('the server did not answer a list');
  if (rows.length >= LIMIT) throw new Error(`${rows.length} official guides: more than this script reads in one request`);
  const records = rows.map(parseGuideRecord).filter((g): g is GuideRecord => g !== null);
  const guides = recordsToBundled(records);
  if (guides.length === 0) throw new Error('the server has no Team Ascent guides (has the import run?). Nothing was written.');
  const out = join(root, 'packages/ui/src/guides/guides.bundled.ts');
  writeFileSync(out, renderBundledGuides(guides), 'utf8');
  console.log(`wrote ${guides.length} guides to ${out}`);
  console.log('now run: npx vitest run packages/ui/src/guides/guides.test.ts   (every card must resolve), then commit the file');
}

main().catch((e) => { console.error(`guides:pull failed: ${(e as Error).message}`); process.exit(1); });
```
