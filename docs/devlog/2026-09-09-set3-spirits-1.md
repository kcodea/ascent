# 2026-09-09 — Set 3 Spirits, tranche 1: the tribe, the Revelers, the Spirits-played engines (17 of 24)

**Owner roster (2026-09-09):** twenty-four Spirits, a brand-new tribe. Rulings taken in-thread: **Reveler** =
the three Reveler minions by id; all three share ONE run-wide value X (starts 1, +1 per Reveler sold, golden pays
2X; Flame → Attack, Tide → Health, Grove → both, to every minion); "your Reveler bonus" IS that X; Treasurer's
discount stacks to −3; Festival Keeper's count carries across turns; Aspect's tally is per copy; **Parade Colossus
→ Forest Colossus**, counting only Spirits played after it; Tidebud / Spiritbringer pay one board AND one hand
recipient; golden doubles; standard frame until Spirit frame art lands; masters in `Set 3 Minions/Spirits`.

Tranche 2 (next) is the **hand-summon** system: "a minion can be SUMMONED from hand once per combat — an exact
copy at the moment of summon, the card stays in hand (greyed for the fight), later hand buffs are not retroactive"
— Dreamtide Caller, Dreaming Deep, Seedling Spirit, plus Handbound Titan, Flamebanner Marshal, Hearth Whisperer,
Slumbering Colossus.

## Engines

- **The shared Reveler value** — `RunState.revelerX` (absent = 1), read by `revelerValue`. `revelerSell` pays
  board AND hand (a Reveler bought late still lifts what you hold), then raises it. Festival Luminary adds it on
  both stats. `REVELER_IDS` (content) is the class the other Spirits name.
- **Spirits played this turn** — derived from `playedThisTurn` (`spiritsPlayedThisTurn`), frozen into combat as
  `CombatSideState.spiritsPlayed` / `ctx.spiritsPlayedFor(side)` for Kindled Sprite; Nurturer reads it at End of
  Turn.
- **`onTribePlayed`** — a new recruit-only trigger fired from `playCard` beside `onSummon` (so a targeted Shout /
  Choose One still counts as a play), reaching BOARD watchers and HAND watchers (`params.inHand`, tranche 2), never
  the played card itself. Per-instance **`spiritTally`** on the body — Festival Keeper's progress, Aspect's trigger
  count, Forest Colossus's Spirits-since — carried through every boundary (BoardCard → BoardMinion → Minion →
  snapshot; the fidelity gate enforces it).
- **Festival Treasurer** — `RunState.spiritDiscount` applied at the buy for a Spirit offer, spent by that buy,
  cleared at the turn flip. **Grand Procession** — `processionReturned` (one return per Reveler type per turn).
- **Live text** — one helper, `spiritText` (cardText.ts), wired into both chains (`instView` + `Unit.tsx`) with
  `revelerX` / `spiritsPlayed` / `spiritTally` threaded through `LiveTextParams`.

## Doc Bot plumbing that a new trigger + tribe needed

`TRIGGER_PHASES` (recruit), `CHANNEL_OF_TRIGGER` (play), a `tribePlayed` **trigger group** — the new event
must be grouped, or its cards fall into the residual bucket and drag their presentation family across two events,
which silently DISSOLVED the owner-decided `q-conv-family-shout` / `-spellCast` questions on regeneration (the
rulebook integrity test caught it). Hence the `onTribePlayed` watchers wear the trigger-keyed `economy` family,
and Dreamcurrent's spellCast watcher wears `castReact` like its peers. A new pending card,
`q-conv-trigger-tribePlayed`, now awaits owner triage. Also: `PHASE_EXCUSED` (four hand/Discover Shouts),
`CARRY_OVER_EXCUSED` (`spiritDiscount`, `processionReturned`), `THIS_TURN_CLASSIFIED` (Kindled / Nurturer /
Treasurer), `PLAY_EXCUSED` (Tidebud / Gathering Guide / Luminary need a Spirit the fixture lacks), the combat
differential pin 1 → 2 (Kindled needs a Spirits-played variant), unresolved-parse 541 → 556, art ratchet → 1130.
