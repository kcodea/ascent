# 2026-10-26: Skins batch 11 (twenty-two minion skins)

The owner asked: "ok i just added a ton of new images to the art folder: C:\Game Assets\Ascent Art\Skins\Minion Skins.
IMPORT them into collections". The folder held 24 masters. Canyon Drake and Thunderchorus Drake were already wired in
batch 9, which left 22 new ones, nearly all Set 2 Beasts. Most are a toy-plushie line; the rest are element or fun spins
on the popular cards picked from purchase telemetry the same day.

Rarity is the folder each master sits in (R-PROG-SKINS-11). Each target was matched by looking at the art.

The art was made with `npm run art:wire -- --only=skins --ids=<the 22 ids> --apply`, which wrote only the 22 new
512px webps. Its gitignored PNG copies were deleted.
