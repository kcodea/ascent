# 2026-10-03: 30 more UI themes (90 total): Basic + Signature, a finish dial, a shortlist, and theme tiers

Owner ask: "can you add 30 more themes for colors? make some 'basic' ones as well, that are simple and clean, as well
as some more unique/in depth ones. we may add these to collections, but im also not 100% sold on a best default yet".

Follows #1926 (60 themes, swatch grid, registry split: see `2026-10-03-ui-themes-60.md`).

- **14 Basic themes** in a new **Basic** optgroup at the TOP of the dropdown: Clean Slate, Midnight, Soft Charcoal,
  Paper Dark, Steel Blue, Forest, Wine, Mono Gold, Mono Silver, Navy, Plum, Mint, Clay, True Black.
  - Near-flat plate (three stops within a few shades), ONE crisp edge colour (all four edge stops equal, so the
    filigree reads as a single thin line rather than turned metal), one accent, a faint ring (alpha 0.12).
  - Mint's ghost is lavender (the teal ghost would share the mint hue).
- **16 Signature themes** in a new **Signature** group (second, under Basic): Sunset Blaze, Borealis, Oil Slick,
  Black Opal, Obsidian Glass, Black Marble, Mother-of-Pearl, Cinnabar Lacquer, Stained Glass, Ember Coal,
  Bioluminescence, Starfield, Tempest, Dragonscale, Celestial Rose, Peacock.
  - Multi-hue plates (Sunset, Borealis, Stained Glass fall through two or three hues; Ember Coal glows hotter toward
    the bottom) and multi-hue edges (Oil Slick, Opal, Borealis, Dragonscale, Peacock).
  - Ghost overrides: Borealis and Peacock pink, Oil Slick and Bioluminescence gold, Opal lavender.
- **The finish dial** (`UI_THEME_FINISH` in `uiThemes.ts`): optional per-theme `sheen` / `bevel` multipliers, written to
  the new `--ui-sheen-strength` / `--ui-bevel-strength` custom properties. `uiTheme.css` declares both as `1` and
  multiplies them into the `--ui-sheen` / `--ui-bevel` alphas.
  - A theme without an entry (all of the original 60) renders exactly as before. Checked by screenshotting Gem,
    Sapphire, Frost and Synthwave with the dials and again with the pre-dial literal sheen / bevel forced back on:
    the only differing pixels were the same ones that differ between two back-to-back shots (the ticking timer, the
    rail's next-foe pulse).
  - Basic: sheen 0.3, bevel 0.45. Signature: 0.9 to 1.9 (Obsidian Glass, Cinnabar Lacquer and Mother-of-Pearl the
    glossiest). Unitless numbers only, so nothing moves.
  - No `--ui-edge-style` token was needed: a flat edge is four equal edge stops.
- **Shortlist** (DEV only, never changes the default): a star per theme in localStorage `ascent.uiThemeShortlist`.
  - Star the current theme with the "☆ Shortlist" button under the swatch grid, or Shift+click any swatch. Starred
    swatches wear a gold star.
  - Starred themes get a "★ Shortlisted" optgroup at the top of the dropdown (they also stay in their own family).
  - The swatch grid has an All / Basic / Shortlisted filter.
- **Tiers** (`UI_THEME_TIERS`: `'basic' | 'standard' | 'signature'`): metadata only, for a future Collection rarity
  mapping. The original 60 are `standard`.
- **Ids stay frozen:** `tooltipStyle.test.ts` now lists every shipped id and fails if one disappears. It also checks
  the tiers match the Basic / Signature groups, the finish dials default to 1 and stay in 0..2, and the shortlist
  helpers.
- Every new theme passes the contrast floors (body / title 7, highlight / muted / warn 4.5, chip 7; the lowest new
  ratio is 5.58) and the 25 degree ghost-hue rule. Distinctness was measured as the mean CIE76 distance over plate,
  edge, title and highlight to the nearest other theme. The closest new pair is 7.5, above the closest existing pair
  (Frost / Glacier, 6.6).
- Dev-only tuner work: no patch note, and no layout change (colour and unitless finish tokens only).
